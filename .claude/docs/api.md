# Справочник API

Базовый URL: `http://localhost:3001/api`  
Swagger UI: `http://localhost:3001/api/docs`

Все защищённые маршруты требуют заголовка: `Authorization: Bearer <accessToken>`

---

## Аутентификация

### `POST /auth/register`

Регистрация нового пользователя. Публичный маршрут.

**Тело запроса**

```json
{
  "email": "user@example.com",
  "password": "secret",
  "name": "Алиса"
}
```

| Поле       | Тип    | Правила                      |
| ---------- | ------ | ---------------------------- |
| `email`    | string | обязательное, валидный email |
| `password` | string | обязательное                 |
| `name`     | string | необязательное               |

**Ответ `201`**

```json
{
  "accessToken": "<jwt>",
  "user": {
    "id": "clx...",
    "email": "user@example.com",
    "name": "Алиса",
    "createdAt": "2024-01-01T00:00:00.000Z",
    "updatedAt": "2024-01-01T00:00:00.000Z"
  }
}
```

---

### `POST /auth/login`

Аутентификация и получение токена. Публичный маршрут.

**Тело запроса**

```json
{ "email": "user@example.com", "password": "secret" }
```

**Ответ `200`** — та же структура, что у `/auth/register`

## Пользователи

### `GET /users/me` 🔒

Возвращает профиль аутентифицированного пользователя.

**Ответ `200`**

```json
{
  "id": "clx...",
  "email": "user@example.com",
  "name": "Алиса",
  "createdAt": "...",
  "updatedAt": "..."

```

## Категории

Все маршруты защищены (`JwtAuthGuard`). Операции ограничены данными аутентифицированного пользователя — категории других пользователей никогда не возвращаются и не изменяются.

### `GET /categories` 🔒

Список всех категорий текущего пользователя.

**Ответ `200`**

```json
[
  {
    "id": "clx...",
    "name": "Еда",
    "color": "#FF5733",
    "icon": "🍔",
    "userId": "clx...",
    "createdAt": "...",
    "updatedAt": "..."
  }
]
```

---

### `POST /categories` 🔒

Создать категорию. Название категории должно быть уникальным для пользователя.

**Тело запроса**

```json
{ "name": "Еда", "color": "#FF5733", "icon": "🍔" }
```

| Поле    | Тип    | Правила                                       |
| ------- | ------ | --------------------------------------------- |
| `name`  | string | обязательное, `minLength: 1`                  |
| `color` | string | необязательное, hex-цвет (например `#FF5733`) |
| `icon`  | string | необязательное                                |

**Ответ `201`** — `CategoryDto`

---

### `PATCH /categories/:id` 🔒

Частичное обновление категории. Все поля необязательны.

**Тело запроса** — любое подмножество полей `CreateCategoryDto`

**Ответ `200`** — обновлённый `CategoryDto`

**Ошибки**

- `404` — категория не найдена или принадлежит другому пользователю

---

### `DELETE /categories/:id` 🔒

Удалить категорию. У существующих транзакций поле `categoryId` становится `null` (Prisma `SetNull` при удалении).

**Ответ `204 No Content`**

**Ошибки**

- `404` — не найдена или не принадлежит пользователю

## Транзакции

Все маршруты защищены. Все операции ограничены данными аутентифицированного пользователя.

### `GET /transactions` 🔒

Список транзакций с опциональной фильтрацией по дате и пагинацией.

**Query-параметры**

| Параметр | Тип    | Правила                  | Описание              |
| -------- | ------ | ------------------------ | --------------------- |
| `month`  | number | 1–12                     | Фильтр по месяцу      |
| `year`   | number | ≥ 1970                   | Фильтр по году        |
| `page`   | number | ≥ 1, по умолчанию `1`    | Номер страницы        |
| `limit`  | number | 1–100, по умолчанию `10` | Элементов на странице |

`month` и `year` работают вместе; передать только один из них допустимо.

**Ответ `200`**

```json
{
  "items": [
    {
      "id": "clx...",
      "amount": "42.50",
      "type": "EXPENSE",
      "description": "Обед",
      "date": "2024-05-10T12:00:00.000Z",
      "userId": "clx...",
      "categoryId": "clx...",
      "createdAt": "...",
      "updatedAt": "..."
    }
  ],
  "summary": {
    "totalIncome": 1000.0,
    "totalExpense": 250.5,
    "balance": 749.5
  },
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 42,
    "totalPages": 5
  }
}
```

> `amount` — строка, потому что Prisma сериализует `Decimal` в JSON как строку.

---

### `POST /transactions` 🔒

Создать транзакцию.

**Тело запроса**

```json
{
  "amount": 42.5,
  "type": "EXPENSE",
  "description": "Обед",
  "date": "2024-05-10T12:00:00.000Z",
  "categoryId": "clx..."
}
```

| Поле          | Тип                       | Правила                                                     |
| ------------- | ------------------------- | ----------------------------------------------------------- |
| `amount`      | number                    | обязательное, положительное, максимум 2 знака после запятой |
| `type`        | `"INCOME"` \| `"EXPENSE"` | обязательное                                                |
| `description` | string                    | необязательное, `maxLength: 500`                            |
| `date`        | string                    | обязательное, формат ISO 8601                               |
| `categoryId`  | string                    | необязательное, должна принадлежать тому же пользователю    |

**Ответ `201`** — `TransactionDto`

---

### `GET /transactions/:id` 🔒

Получить одну транзакцию по ID.

**Ответ `200`** — `TransactionDto`

**Ошибки**

- `404` — не найдена или не принадлежит пользователю

---

### `PATCH /transactions/:id` 🔒

Частичное обновление транзакции. Все поля необязательны.

**Тело запроса** — любое подмножество полей `CreateTransactionDto`

**Ответ `200`** — обновлённый `TransactionDto`

**Ошибки**

- `404` — не найдена или не принадлежит пользователю

---

### `DELETE /transactions/:id` 🔒

Удалить транзакцию.

**Ответ `204 No Content`**

**Ошибки**

- `404` — не найдена или не принадлежит пользователю

---

## Формат ошибок

Все ошибки следуют стандарту NestJS:

```json
{
  "statusCode": 404,
  "message": "Transaction not found",
  "error": "Not Found"
}
```

Ошибки валидации (`400`):

```json
{
  "statusCode": 400,
  "message": ["amount must be a positive number"],
  "error": "Bad Request"
}
```
