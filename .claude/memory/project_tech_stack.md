**TanStack Query** используется для работы с запросами и серверным состоянием.

**Why:** Пользователь явно указал это как стандарт для работы с API-запросами в проекте.

**How to apply:** При предложении паттернов для запросов использовать TanStack Query (`useQuery`, `useMutation` и т.д.), а не голый `fetch`/`axios` или другие подходы.
